# Andini Sari · 17 岁生日庆祝页面

使用 **Vue 3.5.22 浏览器全局版本**，HTML、CSS 和 JavaScript 分开保存。没有 Node.js、npm、Vite、打包或编译步骤。Vue 本身也保存在本地，断网可以打开。

## 使用

直接双击 `index.html`，用 Chrome、Edge、Firefox 或 Safari 打开。发给别人时，请发送整个文件夹或 ZIP，保留各文件的相对路径。

```text
index.html                 页面结构和印尼语祝福文字
css/style.css              颜色、布局、手机适配和动画
css/mobile.css             手机专用字号、单列卡片、触控尺寸
css/motion.css             滑动入场、卡片层次、装饰视差和阅读进度
css/cake.css               奶油蛋糕、细蜡烛、火焰和吹灭动画
css/tulips.css             郁金香插画的布局与轻微摇曳
css/design.css             设计参考图的奶油底色、柔粉排版和纸张卡片
assets/tulip.svg           本地郁金香矢量插画
assets/birthday-kitten-v2.png  首屏水彩小猫、礼盒与郁金香插画
js/main.js                 Vue 应用：许愿、彩纸、祝福信和音乐
js/scroll-motion.js        浏览器原生滚动动画，无编译步骤
js/vendor/vue.global.prod.js  Vue 3 浏览器版本（本地引用）
js/vendor/LICENSE-Vue.txt     Vue 的 MIT 许可证
css/fonts.css              本地字体定义
assets/fonts/              参考样式使用的字体和许可证
```

当前视觉参考 `设计` 文件夹中的方案图：奶油底色、柔粉与浅紫光晕、手写标题、纸张信件和水彩生日插画。首屏使用本地透明背景的小猫、礼盒与郁金香插画；许愿蛋糕使用双层奶油 SVG，配细条纹蜡烛、柔和火焰和奶油花饰。章节之间没有分隔条，背景柔和融合，所有内容连续滚动。`设计` 和旧版 `reference` 文件夹保留原样。

手机使用 `css/mobile.css` 和最后加载的 `css/design.css`：正文 18px，祝福卡、清单和寄语单列显示，主要按钮至少 56px 高；首屏名字分两行放大，插画居中。桌面首屏采用文字与插画并排布局。样式引用带版本号，更新后刷新页面即可加载。手机浏览器应使用移动版网页模式。

点击「Buka kejutan dari kak」撒彩纸并跳转到祝福信；点击蛋糕许愿并吹灭蜡烛，可再次点亮；右上角音乐按钮播放或暂停生日旋律。桌面右侧导航圆点可跳转章节。音乐由浏览器合成，不需要音频下载，也不会自动播放。页面显示文字使用印尼语。

页面按 17 岁少女的语气编写，增加青春寄语、17 张可展开的祝福卡和生日小清单。清单只保留当前页面会话中的勾选，不发送或保存个人信息。

祝福以哥哥的身份写给妹妹：发送者自称 `kak`，称 Andini 为 `dede` 或 `de`。文案表达关心、鼓励、倾听和生日祝福，移除恋爱式表达与密集爱心，仅保留三处小黄心装饰。

首屏的椭圆悬挂装饰和气球已替换为郁金香。信件顶部、结尾小花束、蛋糕与祝福卡也增加郁金香点缀，插画使用本地 SVG，手机保持清晰，装饰不拦截点击。

点击页面任意位置，会从点击处绽放彩色星点粒子。桌面、手机、按钮、链接和复选框点击都支持，键盘激活控件时粒子从控件中心散开。特效不拦截控件操作，快速连续点击最多同时保留 280 个粒子，结束后自动清理。

滑动时，章节标题与正文逐步浮现，卡片轻轻上移展开，同时进入屏幕的卡片错开播放；长信按段落出现。首屏装饰随滚动产生轻微视差，顶部细线显示阅读进度。动画只播放一次，快速跳转与键盘聚焦会立即显示内容，不改变正常滚动方式。系统开启「减少动态效果」时直接显示全文。

首屏后的章节按内容自然排列，取消桌面端每章占满一屏的高度；手机章节间留白缩短。背景使用固定光晕层调整透明度，各章没有独立背景边缘，页脚也不再显示分隔线。展开小寄语或字体加载后，背景融合位置和阅读进度会重新计算。

## 修改

- 姓名、年龄、祝福信、许愿提示：编辑 `index.html` 中对应文字。
- 六张祝福卡的内容：修改 `js/main.js` 中的 `wishes` 数组。
- 17 张小寄语与生日清单：修改 `js/main.js` 中的 `birthdayNotes`、`birthdayPlans` 数组。
- 当前主题颜色、卡片与排版：修改最后加载的 `css/design.css`。
- 蛋糕：修改 `index.html` 中的内联 SVG；火焰和吹灭动画在 `css/cake.css` 中调整。
- 页面使用印尼语，不假设真实生日日期、照片或其他个人经历。

尊重系统「减少动态效果」设置：关闭漂浮、火苗、彩纸和点击粒子动画，背景点缀静止显示。切换到后台时暂停动态效果。蛋糕、音乐、祝福卡、清单和导航支持键盘操作。

## Vue 使用方式

`index.html` 通过普通 `<script>` 引入本地 `vue.global.prod.js`，再加载 `js/main.js`。主脚本使用 `Vue.createApp()`、`ref()` 和生命周期函数；模板通过 `@click`、插值、`v-for`、`:class`、`:aria-pressed` 绑定交互和状态。这是浏览器直接执行的 Vue 用法，无需 `.vue` 单文件组件或构建工具。

可参考 [Vue 官方文档的无构建工具用法](https://vuejs.org/guide/quick-start.html#using-vue-from-cdn)。已固定版本号，运行时不向 CDN 请求文件。

## 本地资源

字体为参考样式使用的 Great Vibes、Poppins 和 Playfair Display，保存在 `assets/fonts`，附 SIL Open Font License。Vue 的 MIT 许可证在 `js/vendor`。

首屏插画 `assets/birthday-kitten-v2.png` 由 imagegen 为本项目生成，包含透明背景；与郁金香 SVG 一起保存在项目内，运行时没有外部图片请求。

旧版生成的 `assets/birthday-cake.png` 和 `assets/art-prompt.txt` 保留供备用，新版页面使用内联 SVG 蛋糕，不需要图片下载。
